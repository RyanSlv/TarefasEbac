# O que é PostgreSQL:



PostgreSQL é um sistema de gerenciamento de banco de dados relacional, gratuito e de código aberto. Ele é utilizado para armazenar, organizar, consultar e alterar  informações.



É muito utilizado em sistemas, aplicações web e projetos de software por ser confiável, seguro e capaz de trabalhar com grandes volumes de dados.



#### Como surgiu?



O PostgreSQL teve origem no projeto POSTGRES, desenvolvido na Universidade da Califórnia em Berkeley, nos Estados Unidos, durante a década de 1980.



O projeto foi liderado pelo professor Michael Stonebraker e tinha como objetivo criar um sistema de banco de dados mais moderno e avançado.



Posteriormente, o sistema passou a utilizar a linguagem SQL e recebeu o nome PostgreSQL. Desde então, continua sendo desenvolvido e atualizado por uma comunidade internacional.



### Como os dados são organizados?



No PostgreSQL, as informações normalmente são armazenadas em tabelas.



Essas tabelas são formadas por linhas e colunas. As colunas representam os tipos de informação que serão armazenados, enquanto as linhas representam os registros cadastrados.



Por exemplo, uma tabela de clientes pode possuir colunas como nome, telefone, e-mail e endereço. Cada linha dessas tabelas representaria um cliente diferente.



#### Relacionamento entre tabelas

#### 

Uma das principais características de um banco de dados relacional é a sua possibilidade de criar relações entre diferentes tabelas.



Essas relações normalmente são feitas utilizando chaves primárias e chaves estrangeiras.



A chave primária identifica cada registro de forma única dentro de uma tabela. Já a chave estrangeira permite relacionar informações de uma tabela com a outra.



Por exemplo, uma tabela de pedidos pode estar relacionada a uma tabela de clientes para identificar qual cliente realizou cada pedido.



#### O que é SQL? 



SQL significa Structured Query Language, ou Linguagem de Consulta Estruturada.



É a linguagem utilizada para se comunicar com o banco de dados. Por meio do SQL, é possível criar tabelas, cadastrar informações, realizar consultas, alterar registros e excluir dados.



O SQL é utilizado não apenas no PostgreSQL, mas também em diversos outros sistemas de banco de dados.



#### Principais características do PostgreSQL:



O PostgreSQL é conhecido por ser um banco de dados seguro, confiável e bastante completo.



Ele pode ser utilizado tanto em aplicações pequenas quanto em sistemas que trabalham com grandes quantidades de informações.



Também possui recursos como transações, índices, funções, views e triggers, além de permitir o controle de usuários e permissões.



Por ser gratuito e de código aberto, é bastante utilizado tanto para estudos quanto em aplicações profissionais.



#### PostgreSQL e java



O PostgreSQL pode ser utilizado junto com diversas linguagens de programação, incluído o java.



Em uma aplicação Java, o programa pode se conectar ao PostgreSQL para cadastrar, buscar, alterar ou excluir informações do banco de dados.



Dessa forma, o Java fica responsável pela lógica da aplicação, enquanto o PostgreSQL fica responsável por armazenar e gerenciar as informações.
